# Java Projects: Scientific Calculator & Tic-Tac-Toe

A collection of two desktop applications built using Java and Swing for the Graphical User Interface (GUI). Both projects are configured and ready to run inside Visual Studio Code.

## 📌 Projects Overview

### 1. Scientific Calculator
A fully functional calculator capable of performing standard arithmetic as well as advanced scientific calculations.
*   **Basic Operations:** Addition, subtraction, multiplication, division.
*   **Scientific Functions:** Trigonometry (sin, cos, tan), logarithms (log, ln), exponents (x², \(x^y\)), square roots, and factorials.
*   **User Interface:** Clean, grid-based Swing layout with a clear digital display.

### 2. Tic-Tac-Toe Game
A classic, interactive two-player board game.
*   **Gameplay:** Alternating turns between Player "X" and Player "O".
*   **Logic Engine:** Automatically detects win conditions (rows, columns, diagonals) and tie games.
*   **Visual Feedback:** Highlights the winning combination and features a reset button to instantly start a new match.

## 🚀 Getting Started in VS Code

Follow these steps to set up and run the applications on your local machine:

### 1. Clone the Repository
```bash
git clone https://github.com
cd YOUR_REPOSITORY_NAME
```

### 2. Open in VS Code
Open VS Code, select **File > Open Folder...**, and choose the cloned repository folder.

### 3. Run the Applications
1. Navigate to the `src` folder in the VS Code Explorer sidebar.
2. Open the main Java file you want to run (e.g., `Calculator.java` or `TicTacToe.java`).
3. Click the **Run** button appearing above the `main` method, or press `F5` on your keyboard to start debugging.
